# 受控版型庫

依**資訊關係**分配版型，不要依裝飾效果。

| 關係 | 版型 ID | 構圖 |
|---|---|---|
| focus 聚焦 | `cover_hero`、`question_focus` | 一個主導主張＋一個焦點畫面 |
| contrast 對比 | `misconception_dual`、`comparison_split` | 兩側平衡或加權對照 |
| sequence 流程 | `process_timeline` | 三到五個有序步驟 |
| classification 分類 | `classification_grid` | 2x2 或 2x3 分組 |
| scenario 情境 | `case_scene_analysis` | 情境加上詮釋 |
| hierarchy 層級 | `relationship_map` | 分層、樹狀或中心放射 |
| causal 因果 | `relationship_map` | 由因到果的鏈條 |
| metric 數據 | `data_focus` | 一個數字或一張圖表＋一句結論 |
| synthesis 收斂 | `summary_three` | 三個要點＋一句核心句 |
| action 行動 | `action_next_step` | 明確的下一步或檢查清單 |
| section 分段 | `section_divider` | 滿版轉場＋一行字 |

規則：

- 同一個版型不可連續使用超過兩次。
- 滿版構圖主要用在封面、分段頁與結尾頁。
- 版型超出可容納的項目數時，把內容拆成兩頁。
- 可以左右交替視覺重心，但不可改變固定的視覺語法。
