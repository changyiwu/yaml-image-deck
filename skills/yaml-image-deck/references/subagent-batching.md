# Subagent 分批生圖

只有在**使用者明確要求平行生成、且當前環境支援 subagent** 時才使用。

1. 先用序列方式生成並確認一張黃金樣張。
2. 把它存進專案，並將路徑寫入 `design_system.style_reference`。
3. 把**不重疊**的頁面範圍分配給各個 worker。
4. 每個 worker 都拿到相同的 `spec.yaml`、黃金樣張、prompt 合約、輸出目錄與字體政策。
5. 要求每頁一次生圖呼叫、在本地存檔、肉眼檢查，並各自留下獨立的 prompt log。
6. 不可讓多個 worker 改到同一個檔案。
7. 主 Agent 負責檢查最終拼接圖，並重生風格漂移的頁面。

平行 worker 只能縮短等待時間，**不會增加生圖額度，也不保證風格一致**。
